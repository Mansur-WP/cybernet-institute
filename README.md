# Cybernet Computer Institute Portal

A modern, full-stack web application built for the Cybernet Computer Institute. This portal provides a seamless digital experience for student registration, certificate verification, and administrative management.

## 🚀 Features

- **Student Registration (`register.html`)**
  - Clean, responsive registration form.
  - Auto-generation of unique Registration IDs (e.g., `CCI-2026-0001`).
  - Duplicate email prevention.
- **Certificate Verification (`verify.html`)**
  - Public portal for verifying the authenticity of student certificates.
  - Instant database lookup returning student grade, course, and date of completion.
- **Secure Admin Dashboard (`admin.html`)**
  - Protected by **Supabase Authentication** (Email & Password).
  - View real-time tables of registered students and issued certificates.
  - **One-Click Issuance**: Easily issue official certificates to registered students with matching IDs.
- **Premium UI/UX**
  - Custom, lightweight Vanilla CSS styling.
  - Beautiful modal popups powered by SweetAlert2.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Backend & Database**: [Supabase](https://supabase.com/) (PostgreSQL)
- **Authentication**: Supabase Auth
- **Alerts**: SweetAlert2

## 📦 Setup & Installation

Because this project uses a serverless architecture, no local backend setup is required. The frontend communicates directly with Supabase via their JS SDK.

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```
2. **Open the project:**
   Simply open `index.html` (or any other HTML file) in your preferred web browser. No local development server is strictly necessary, though you can use tools like VS Code Live Server for a better development experience.

## 🗄️ Database Schema (Supabase)

To replicate the backend environment, you need two tables in your Supabase project:

### 1. `students` Table
```sql
create table public.students (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  fullname text null default ''::text,
  phone bigint null,
  email text null,
  gender text null,
  course text null,
  reg_no text null,
  constraint students_pkey primary key (id)
);
```

### 2. `certificates` Table
```sql
create table public.certificates (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  student_name text null,
  cert_no text null,
  course text null,
  completion_date text null,
  status text null,
  constraint certificates_pkey primary key (id)
);
```

## 🔐 Security (Row Level Security)

For the system to function correctly, Supabase Row Level Security (RLS) must be configured:

- **Students Table**:
  - `INSERT`: Allowed for public (anon) so anyone can register.
  - `SELECT`: Allowed for public (or authenticated) so the admin dashboard can read them.
- **Certificates Table**:
  - `SELECT`: **MUST** be allowed for public (anon) so the `verify.html` page can check certificates.
  - `INSERT`: Allowed for authenticated users only, so only admins can issue certificates.

Example Policy for Verification:
```sql
-- Allow anyone to read the certificates for verification
CREATE POLICY "Allow public read access to certificates" 
ON public.certificates FOR SELECT USING (true);
```

## 👨‍💻 Administration

To access the Admin Portal:
1. Create a user via your Supabase Authentication dashboard.
2. Navigate to `admin.html` in the browser.
3. Log in with those credentials to manage students and issue certificates.
